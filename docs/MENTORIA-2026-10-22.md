# Estudo guiado: validação não é comprovação de identidade

A função central abaixo está em `app/vault/contracts.py`. É usada por `check_value` após a extração de um campo explicitamente identificado como CPF.

```python
def valid_cpf(value):
    digits = re.sub(r'[.\-\s]', '', value)
    if not re.fullmatch(r'[0-9]{11}', digits) or len(set(digits)) == 1:
        return False
    for size in (9, 10):
        total = sum(int(digits[index]) * (size + 1 - index) for index in range(size))
        check = (total * 10 % 11) % 10
        if check != int(digits[size]):
            return False
    return True
```

1. `def`: recebe uma string, não um objeto de cliente. Retorna somente verdadeiro/falso.
2. `re.sub`: remove pontuação e espaços permitidos. Não elimina letras: conteúdo inesperado deve ser recusado, não consertado silenciosamente.
3. `fullmatch`: exige exatamente onze algarismos ASCII; `set` identifica sequências com um único dígito repetido.
4. `return False`: encerra antes de tentar converter texto inválido em inteiros.
5. `for`: calcula os dois dígitos verificadores, primeiro com nove algarismos e depois com dez.
6. `sum`: aplica pesos decrescentes aos algarismos. É o mesmo conceito de laço acumulador de Java/C#, expresso por uma compreensão em Python.
7. `%`: calcula o resto; o segundo módulo transforma o resultado dez em zero.
8. `if`: compara o dígito calculado com o informado.
9. `return False`: uma divergência basta para recusar o formato.
10. `return True`: os dois dígitos passaram. Não prova que o CPF pertence à pessoa ou sequer que o cadastro existe.

O contrato da função exige string; um chamador que passe `None` causa TypeError. Na extração, o valor é convertido para string antes da chamada. Sem a linha 3, letras poderiam causar ValueError e dígitos repetidos poderiam passar. Sem a comparação da linha 8, o cálculo não teria efeito. Alterar os pesos invalida a verificação.

A alternativa seria uma biblioteca de documentos brasileiros. A função pequena facilita auditoria e testes, mas exige manutenção cuidadosa; não substitui validação cadastral autorizada. Não consultar serviço remoto aqui mantém a validação local e barata. O resultado de `check_value` aparece na demonstração com a ressalva de que formato não comprova identidade.

## Conceitos para estudar

Validação sintática versus semântica; funções puras; testes de propriedades; recusa por padrão; cifragem autenticada; separação de domínios; imutabilidade de referências em testes adversariais.
